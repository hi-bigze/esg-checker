## 填表规则（只有五条）

1. `disclosed` 只填三个值之一：**是 / 否 / 部分**
   - 是 = 明确披露了且能拿到数值或明确表述
   - 部分 = 提了但不完整（如只说方向没给数、只有强度没给总量）
   - 否 = 全文找不到
2. `value` / `unit` **照抄原文**，不要换算、不要四舍五入。原文是「/」或「—」就照抄「/」。
3. `page` 填你实际看到的那一页。**填不出页码，就是「否」**——这条纪律要严格执行，它防止你凭印象打分。
4. `evidence_quote` 抄一句原文（10–40 字），必须是你判断的直接依据。
5. 拿不准的，`notes` 里写「判不了：原因」，不要猜。**「判不了」是有效数据，猜是污染数据。**

## 附：10 条规则完整定义（填表时对照用，唯一以 `rules/ghg_v1.yaml` 为准）

| 规则 | 名称 | 判什么 |
|---|---|---|
| GHG-01 | 范围一温室气体排放总量 | 是否有绝对量（tCO2e），是否与范围二分开，单位是否规范 |
| GHG-02 | 范围二（基于位置） | 是否有基于位置的值，是否明确标注口径 |
| GHG-03 | 范围二（基于市场） | 非强制项；若披露，是否说明绿电/证书依据 |
| GHG-04 | 组织边界界定方法 | 是否写明股权比例法/财务控制权法/运营控制权法之一；变更是否重述 |
| GHG-05 | 运营边界与排放源识别 | 是否列出范围一排放源类型（固定燃烧/移动燃烧/逸散/工艺）+ 范围二类型（外购电/蒸汽/供热/制冷） |
| GHG-06 | 核算标准与排放因子来源 | 是否写明标准名称（GHG Protocol / ISO 14064 / 国家指南）+ 因子来源 + 跨年一致 |
| GHG-07 | 基准年与基准年排放 | 有减排目标就必须有基准年、基准年排放量、重算规则 |
| GHG-08 | 排放强度指标 | 若披露强度，分母是否明确（营收/产量/面积），口径是否前后一致 |
| GHG-09 | 范围三排放 | 是否纳入、覆盖 GHG Protocol 哪几类、初级数据还是估算 |
| GHG-10 | 第三方鉴证 | 机构名称 + 覆盖范围 + 保证等级（有限/合理）三项是否齐全 |
