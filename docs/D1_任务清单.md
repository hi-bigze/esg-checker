# D1 任务清单：手工核查 3–5 份真实报告

## 这一天到底在干什么

不是学 ESG，是**验证规则库能不能被机器执行**。

你现在担心的「专业不够」，在这一天的实际形态是：拿 10 条规则去对真实报告，看哪几条一眼就能判、哪几条判不了。判得了的留给机器，判不了的标 `auto: false` 交给人。

**D1 结束的标志不是「我懂 ESG 了」，是「我知道这 10 条里，机器能扛几条」。**

### 你还需要自己补 1–2 家「披露差的」

这三家质量都太好，跑出来全是绿灯，演示没价值。**你必须找到一份披露不完整的报告**，工具的价值才看得见。

筛法（任选）：
1. 巨潮搜「可持续发展报告」，按披露时间排（2026 年 3–4 月），挑**页数少于 60 页**的
2. 优先看**建材、纺织、轻工、基础化工**等中等市值制造业——排放源多、披露压力大、编制人手少
3. 打开后直接看：有没有「温室气体排放表」？没有的就是目标样本

参考事实：2025 年度 A 股温室气体排放量的披露率只有 **37%**，强制披露主体里也存在只说定性不给数据的情况。

## 核查表怎么填

新建一个 Excel 或 CSV，字段固定：

| 字段 | 填什么 |
|---|---|
| 公司 | 简称 |
| 规则ID | GHG-01 … GHG-10 |
| 是否满足 | 是 / 否 / 部分 |
| 证据页码 | 第 X 页（必须填，页码是后面产品的核心功能） |
| 原文摘录 | 不超过 50 字，能支撑判断的那句 |
| 缺陷描述 | 人话写清楚缺什么 |
| 机器能判吗 | 能 / 不能 / 存疑 |
| 为什么 | 一句话说清机器判不了的原因 |

### 两条硬规矩

1. **必须人工填，不许用 AI 代填。**
   这是 ground truth。用 AI 填，D3 就没法验证 AI 准不准，整个项目的说服力归零。

2. **证据页码必须填。**
   产品里每一条结论都要能跳回原文。页码填不出来，说明你自己也没真找到，那这条不算数。

## 结束时要能回答三个问题

1. 10 条规则里，哪几条是**纯 mechanical**（有/没有、单位对不对）？
2. 哪几条**必须读上下文**（比如「合并范围是否与财务报告一致」）？
3. 哪几条**你自己也判不了**？——这三条直接删掉或降级为「提示」，不要硬做。

第 3 个问题最重要。**敢删规则的人才做得成产品**，硬凑 10 条全做的，最后一条都对不准。

---

## 常见卡点

- **找不到排放数据** → 先搜「温室气体」「碳排放」「Scope」「范围一」四个关键词，有时放在「环境绩效表」而非气候章节
- **单位不统一** → 统一换算成 tCO2e 再填表，换算过程记在备注里（这本身就是产品要解决的痛点）
- **看不懂某条要求** → 直接查依据原文，规则库里每条都给了出处链接，20 分钟内能搞明白
- **整份报告都是定性描述没有数据** → 这正是最好的样本，别换掉
